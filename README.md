# Zibo Boss Tracker (Zibo Searcher)

**Zibo Boss Tracker** — это профессиональное веб-приложение (PWA) для Telegram, разработанное специально для игроков MMORPG **Royal Quest**. Приложение полностью автоматизирует отслеживание времени возрождения мирового босса **Зибо (Мимик)**, визуализирует его маршруты и предоставляет глубокую аналитику на основе накопленной статистики.

---

## ⚡ Основные возможности

### 📊 Дашборд (Главный экран)
*   **Динамический статус-блок:** Мгновенное отображение состояния босса (Ожидание / Поиск / Окно закрыто / Офлайн).
*   **Визуальные индикаторы:** Цветовая кодировка статусов с плавной анимацией для быстрого считывания информации.
*   **Маршрутный лист:** Детальная визуализация 120-минутного цикла ротации (12 слотов по 10 минут). Каждая строка отображает текущий список локаций для активного поиска.
*   **Последняя смерть:** Таймер обратного отсчета с момента последнего подтвержденного убийства, сопровождаемый тематической анимацией.

### 🔬 Аналитические инструменты
Приложение использует математические модели и накопленную базу данных для высокоточного прогнозирования:
1.  **Цепи Маркова (Markov Chains):** Анализ вероятностей перехода между локациями первого и второго порядка (Откуда -> Где -> Куда).
2.  **VTP (Weighted Respawn Points):** Расчет наиболее вероятных точек респауна на основе исторических весов каждой локации.
3.  **Frankenstein:** Уникальный алгоритм анализа паттернов перемещения, учитывающий "дрифт" времени и формирующий кластеры магнитных точек появления.
4.  **Master Table:** Автоматическая калибровка кулдаунов (CD) на основе корреляции времени простоя и времени жизни сервера.
5.  **Chain Analysis:** Прогноз последовательности респаунов на несколько шагов вперед.
6.  **Retro Analysis (Sandbox):** Полноценный режим симуляции, позволяющий проверять гипотезы, "перематывая" время в прошлое или будущее.

### 🗄 Архив и Администрирование
*   **История событий:** Единый лог смертей, находок (sight) и технических работ с удобными фильтрами.
*   **Ролевая модель:** Разграничение прав на администраторов (управление данными и пользователями) и зрителей.
*   **Управление пользователями:** Встроенная панель для выдачи прав доступа по ID или Username.

### 🎮 Дополнительно
*   **Casino Zibo Bet:** Интерактивная рулетка для развлечения участников во время длительного ожидания босса.
*   **PWA & Telegram Integration:** Полная поддержка Telegram Web Apps SDK, включая светлую/темную темы и адаптивность под мобильные устройства.

## 🚀 Установка и запуск

### 1. Клонирование
```bash
git clone https://github.com/Kraymberg/ZiboSearcher.git
cd ZiboSearcher
```

### 2. Зависимости
```bash
npm install
```

### 3. Настройка Firebase
Создайте проект в Firebase Console, включите Firestore и пропишите конфиг в `firebase.ts`. По умолчанию права доступа проверяются в коллекции `users`.

### 4. Запуск
```bash
npm start
# Доступно по адресу http://localhost:8080
```
